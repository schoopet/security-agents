# Security Agent Samples

A collection of sample agents and scripts demonstrating security-relevant behaviors in deployed AI agent environments, built on Vertex AI Agent Engine.

## Samples

| Directory | Description |
|---|---|
| `agents/remote-exec` | Remote interactive code execution via a deployed agent's query handler; includes cert and token analysis for workload identity credentials |
| `agents/context-agent` | Deployed agent exposing full session, memory, and sandbox management via a text command interface; also supports model calling, environment variable inspection/mutation, Cloud Logging, and token/credential introspection |
